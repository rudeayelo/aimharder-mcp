# Playful rock target pose

Created 2026-10-29 with the built-in GPT Image tool after the owner chose the playful rock as the next emote, deferring surprise because it overlaps with delight. The [neutral master](../../reference-pack/01-front-neutral.png) was the edit target. [The generated pose](rock-left.png) depicts a small screen-left lean with the same blue character and neutral eyes.

The [image prompt](image-prompt.txt) requests about an eight-degree in-plane lean, pivoting on the left base edge while the rigid body, open handle, circular face and eyes rotate together. Visual inspection confirms the intended grounded-lean direction and overall identity; the exact angle, true rigid geometry, unchanged scale and pixel-identical material preservation are not established by a generated still. Fine proportions, eye rims and texture may vary. Owner review of this reference remains pending.

The image is copied unchanged from the built-in tool into the project. [Manifest](manifest.json) records actual dimensions, bytes and SHA-256. It is supplied as a middle keyframe in [the guided rock video](../trial-06-guided-rock/README.md), with the same neutral master at both endpoints. The [video prompt](guided-video-prompt.txt) requests a smaller opposite lean as the recovery, then an upright stop; eyes stay neutral throughout. No Runway image-generation task was used.
